        Methodology & scope

        1. StatsBombopen event data
        2. football-analyticsdata/ → analytics/ (the Python package)
        3. scripts/data_pipelineprecomputed JSON
        4. This sitestatic HTML/JS
        • Every number on this page is precomputed from StatsBomb's open data, no API calls happen once this page has loaded.
        • FootballDataClient (which needs a football-data.org API key) is intentionally excluded from this web demo, to keep the deployed site free of secrets and external calls, though the underlying football-analytics package supports it for programmatic use.
        • The full 2015/16 LaLiga season: every team, every player who appeared, all 380 matches. A second season (2014/15) feeds a small season-over-season trend for nine notable players only, since StatsBomb's open data is heavily Barcelona-centric outside the full 2015/16 season.
        • Player names are shown as StatsBomb's own short nickname where it has one (e.g. "Lionel Messi"), falling back to their full name otherwise.
